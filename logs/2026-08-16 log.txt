5. FluidCanvas v9.3 — Rotation for ALL cards (rotate grip + fixed right-click entry)
   - User request: "add rotation to all cards, including cards added later".
     Confirmed design (AskUserQuestion): Canva-style rotate grip above the
     selected card as the primary entry + fix the right-click slider popover
     (kept for exact angles).
   - Root cause: rotation existed end-to-end (rotateCard, context-menu item,
     slider popover, save/load all already carried the rotate field), but the
     right-click entry called getRotatePopover() which was never defined →
     ReferenceError → entry unreachable. Same bug class as the v9.1 flag
     modal (feature exists, entry dead). Fixed with one line next to
     getRadiusPopover.
   - Rotate grip: 16px circle (--color-primary-fixed, grab/grabbing cursor)
     + 2px stem connecting to the card bbox top; pooled elements appended to
     gridCanvas (same coordinate system as the resize handles).
     refreshRotateGrip(): cx=x+w/2, cy=y+h/2, rotation-aware half-height
     hh=(|w·sinθ|+|h·cosθ|)/2, grip center at (cx, cy−hh−28); top clamp
     gripY = max(8, cy−hh−28) and the stem hides when the grip bottom falls
     below the bbox top (grip never sticks out of the canvas on cards pinned
     to the top boundary). Single mount point INSIDE refreshResizeHandles →
     every existing refresh path (select/deselect/drag/resize/rotate/delete/
     move) covered with zero new call sites and no card-type branches, so
     "all cards including future ones" holds automatically.
   - Drag pipeline: beginRotate converts canvas coords to client coords and
     records a0 + startRot; onRotateMove computes rot = startRot + (atan2−a0)
     with a while-loop folding the delta into ±180 (no seam tumble),
     Shift = 15° snap (Canva standard), writes dataset.rotate + transform,
     then clampCardToPage (rotation changes the bbox → card stays in page)
     and updateDangerGuides (v9.2 integration: rotating into the boundary
     lights the 4 red lines), highlightCardCoverage + refreshResizeHandles.
     mouseup and Escape share commitRotate: normalize to (−180,180],
     moveCardPx (clamp + dataset.x/y), onContentChange. Escape COMMITS
     (same single rule as resize). No justDragged flag (grip is not a card
     child, click never bubbles to the card).
   - Badge + self-check: FC v9.3 / ready (v9.3). Draft v stays 9 (rotate
     was already persisted).
