SUBNAV SLIDING HIGHLIGHT (SLIME ANIMATION)
============================================================

Created docs/assets/js/subnav.js — shared component:
- Auto-initializes on all .subnav[data-slider] elements
- Injects white highlight pill + trailing purple blob
- CSS transition 0.55s cubic-bezier(0.25,0.1,0.25,1) matching panel slide speed
- Slime stretch effect on tab switch (scaleX 1.06 → 0.97 → 1.0)
- Trailing blob fades out at old position
- Shadow depth: 0 2px 12px rgba(0,0,0,0.08) + 0 1px 3px rgba(0,0,0,0.06)
- MutationObserver for programmatic tab changes
- Resize handler for repositioning

Updated CSS:
- .subnav-pill.active: background → transparent, box-shadow → none
  (highlight pill handles the white background + shadow)
