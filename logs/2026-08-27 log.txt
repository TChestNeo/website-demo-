## 2026-08-27 — 国徽卡「放大缩小不跟随鼠标」修复（v10.28.7.1）

**背景**：用户问询定位=国徽卡片。

**改动**：真身 = 锁定缩放投影公式分母误为 (w0²+h0²)/2——角把手以 2× 鼠标速度沿角射线甩开光标，注释原称「Exact when the mouse follows the corner ray」实为 2 倍响应。修 = 分母 w0²+h0² 标准角射线投影：沿射线拖角把手与鼠标 1:1 贴齐、偏轴拖标准投影等比、方向/最小钳制/旋转换算不变。

**验证**：冒烟 15/15 0 console error（真鼠 Input.dispatchMouseEvent：射线 1:1 / 偏轴投影期望值 / 非锁定回归 / 旋转 30° 局部跟手 / 版本徽章）。

**教训**：代码注释自称 exact 的公式也要拿数字验一遍——(w0²+h0²)/2 与标准投影差 2 倍，纸上一算即知。

## 2026-08-27 — SNE Index 卡片（v10.28.8）

**背景**：用户「减去掉 Governance 和 Economic Ledger 卡片 并且添加 SNE Index卡片（Slati National Equilibrium Index | 斯拉蒂国家平衡指数) 算法之后再做，然后卡片展示方式是 中间正上方 总分下方是 长x宽 3x2 政治 经济 军事 外交 基本信息完整度 国家系统；然后该卡片一样可以编辑边缘 一样要做一下增加边距避免超出范围 然后每个指标都是一个二级小格子 然后我希望你 在这些格子的下方再添加一个卡片给这个卡片添加阴影 然后再添加Overflow: hidden值把主要的卡片框进去或者单独的二级卡片框进去做出边缘虚化的效果」。问询钦定：算法先占位简单平均（之后换公式只改 sneComputeTotal 单函数）、完整度先手动打分（之后自动关联国家信息）。

**改动**：
1. 资产面板移除 account_balance/payments 两模板（旧草稿 createAssetCard 兜底载入）、新增 SNE Index 卡（balance 图标）。
2. 结构 = .sne-shadow 阴影子层（z -2 inset 0 透明底 + 硬边 offset box-shadow = 垫在卡下第二张卡片，主题边缘/外板时 CSS 隐藏——板自带阴影职责）+ .sne-inner 内容区（overflow:hidden + border-radius:inherit 剪齐卡角 + 径向渐隐遮罩边缘虚化）+ .sne-head 总分上方居中 + .sne-grid 3×2 六指标二级小格（政治/经济/军事/外交/基本信息完整度/国家系统，各带 0-100 数字输入 .card-edit-field 不 arm 拖拽）。
3. dataset.sneData additive 草稿往返（restoreSne 重建六格）。
4. 边缘主题同国旗/数据卡口径——六处 .card-label 门禁放开 sne（setCardEdge/applyCardBg/applyOuterBg/背景菜单/移除背景/openCardBgPopover）+ 油漆边距 v10.28.6.1 同款 container-type:inline-size + cqi 四边内边距。

**验证**：冒烟 26/26 0 console error（面板增删/工厂结构/平均总分/sneData 序列化/paint2 边缘+阴影隐藏+cqi 边距/背景图上传提层+移除门禁/草稿存取/重载还原/legacy account_balance 兜底/sne 无数据默认/版本徽章）。

**教训**：阴影子层设计——「垫在下面的卡片」不能用 inset 负值+实底色（负 z 子层画在卡自身背景之上会盖暗卡面），改 inset 0 透明底 + box-shadow 画在盒外天然不被父 overflow 裁剪且跟圆角；主卡 overflow:hidden 与阴影探出卡外不可兼得——用户给的两选一（框主卡或框二级格）选后者。

## 2026-08-27 — SNE 卡默认尺寸 6×5 → 9×12（v10.28.8.1）

**背景**：用户「能不能调整一下他被脱出来的时候的默认大小，现在这个大小显示不完整」。

**改动**：
1. 真身 = 运行时格宽 20px（非内联 style 的 24px，probe 实证 computed --cell-size=20）——6×5 = 130×108 装不下两行标题+总分+2 行六格，overflow:hidden 裁掉一切、nowrap+省略号截断「基本信息完整度」。
2. 默认 9×12（196×262）留足余量 + 内容收紧（总分 36→32、格子纵向间距 3→2、网格底衬 8→12、指标名 white-space:normal 折行显示全名）。
3. 三处默认值同步（assetSpan/createSneCard/草稿恢复 pos.colSpan||9）。

**验证**：冒烟 21/21 0 console error（默认尺寸按格宽数学断言 + inner 无裁剪 + 名字/标题全显 + paint2/5 大边距下格子级无溢出 + 草稿往返 + 重载还原）。

**教训**：卡默认尺寸设计要看运行时 --cell-size 而非内联 style 声明值——电池断言尺寸按 computed cell 数学算，别写死常数。

## 2026-08-27 — SNE 卡字幕全部中间对齐（v10.28.8.2）

**背景**：用户「SNE Index能不能把卡片内的字幕都中间对齐？」。

**改动**：
1. 标题/总分/指标名/数值 CSS 本就 text-align:center——不居中的真身 = 数值框 number 原生步进钮（Chrome 悬停/聚焦时占右侧挤窄编辑区，text-align:center 只在缩水后的编辑区内居中 → 数字视觉偏左）。
2. 修 = .sne-val appearance:textfield（+ -moz 同款，步进钮整体消失、数字死居中）+ 总分补显式 text-align:center。
3. ::-webkit-inner/outer-spin-button 规则留旧版兜底——Chrome 151 步进钮已非可查伪元素（probe 实证连原生默认号输入的伪元素查询都返回空），断言口径改为 input 自身 computed appearance=textfield vs 原生对照 auto。

**验证**：冒烟 15/15 0 console error（标题/总分/六指标名 Range 紧包围盒中心 vs 容器中心 ≤1.5px 几何断言 + 六数值框中心 + 改值总分 + 草稿往返 + 重载还原）。
