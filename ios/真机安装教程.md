# 把 App 装到你的 iPhone（免费方法，不用 Mac）

这个方法用的是苹果的**免费开发者侧载**：不花钱，但签名 7 天过期，过期后重新装一次就行（1 分钟）。

## 准备（只做一次）

1. **下载安装包**：打开 GitHub 仓库 → 顶部 `Actions` 标签 → 点最新一条绿色 ✓ 的记录 → 页面底部 `Artifacts` 里下载 `MNationWorld-unsigned-ipa` → 解压得到 `MNationWorld-unsigned.ipa`。
   （仓库地址：https://github.com/TChestNeo/website-demo-）

2. **Windows 装两个东西**：
   - iTunes（必须去苹果官网下载「Windows 版」，不要 Microsoft Store 那个）：https://www.apple.com/itunes/download/
   - Sideloadly（免费侧载工具）：https://sideloadly.io/

3. **iPhone 数据线连电脑**，手机上点「信任此电脑」并输锁屏密码。

## 安装（每次 1 分钟）

1. 打开 **Sideloadly**。
2. 把 `MNationWorld-unsigned.ipa` 拖进 Sideloadly 窗口。
3. 填你的 **Apple ID**（就是你登录 iPhone 的那个邮箱）。
4. 点 **Start**，等它跑完（首次约 1-2 分钟）。
5. 手机上会出现 **M.NationWorld** 图标。
6. 第一次打开会提示「不受信任的开发者」：去 设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任。之后再打开就正常了。

## 7 天过期怎么办

签名 7 天后 app 会打不开。重新做一遍「安装」步骤即可（数据还在）。

## 常见问题

| 问题 | 解决 |
| --- | --- |
| Sideloadly 报「找不到设备」 | 确认 iTunes 装的是苹果官网版；换根数据线；手机上重新点「信任」 |
| 提示「Apple ID 需要双重验证」 | Sideloadly 会要求 app 专用密码：去 appleid.apple.com 登录 → 登录与安全 → App 专用密码 → 生成一个填进去 |
| 装到第 4 个 app 装不下 | 免费账号最多同时装 3 个自签名 app，删掉旧的重装 |
| 想无线重签（不用每次插线） | 改用 AltStore：手机装 AltStore 后，同一 WiFi 下自动刷新签名 |

## 以后正式上架（可选）

想上 App Store 正版（别人也能搜到下载）时，需要：
1. 注册付费开发者：https://developer.apple.com/programs/（99 美元/年）
2. 一台 Mac（或云 Mac）——代码已经是现成的，打开就能打包上传。

在那之前，这个免费方法足够你随时在手机上查看开发进度。
