诊断链：
- 探针 tmp-probe-msg-anim.js v2（transition/animation 事件开窗只计动画进行中帧、3 轮中位、暖机先行）

  软件渲染管线无法验证 GPU 合成修复的真 FPS（noblur 注入 .card{backdrop-filter:none} 数值不变 = 帧节奏与内容无关实证）。

   style.opacity 0.3/1 保留只是不再过渡）
③ announceList CSS mask 移除（mask 强制滚动/滑动逐帧重栅格列表区）
④ 19 处 transition:all → 显式属性列表（.btn/.input-glass/.modal-card/.card-hover/.subnav-pill/.upload-zone/

⑤ 侧栏折叠 width 0.3s ease → 0.25s cubic-bezier(0.22,0.61,0.36,1)（×2 convSidebar/groupSidebar）
⑥ .msg-row.fade-up { will-change:transform,opacity }
⑦ .card-hover 过渡移基类（悬停抬升双向平滑，原 :hover 单向）
