                    M.NationWorld 隐私政策 (Privacy Policy)
================================================================================

生效日期：2026年8月13日

M.NationWorld 极其尊重用户的个人隐私与数据安全。本隐私政策旨在告知您我们如何收集、使用、存储及保护您的个人数据。

--------------------------------------------------------------------------------
1. 我们收集的信息
--------------------------------------------------------------------------------
我们遵循“数据最小化”原则，仅收集维持服务正常运行所必需的信息：
• 账号基础信息：电子邮箱地址、用户名、Discord User ID（若使用 Discord 快捷登录）。
• 支付与订阅数据：交易流水号、订阅方案与到期时间（注意：信用卡号及银行敏感信息由第三方支付网关如 Stripe / FPX 直接处理，M.NationWorld 绝不存储您的敏感支付凭证）。
• 系统与日志信息：登录 IP 地址、浏览器类型、设备信息及 API 调用日志（用于安全风控与防 DDoS 攻击）。

--------------------------------------------------------------------------------
2. 信息的使用目的
--------------------------------------------------------------------------------
收集的数据仅用于以下核心业务场景：
1) 为您提供 M.NationWorld 平台的核心功能与定制算力服务。
2) 处理您的订阅订单、开具发票与解决售后技术问题。
3) 监控系统健康状况，识别并防御恶意网络攻击或欺诈行为。
4) 向您发送必要的系统通知、版本更新或法律文档变更通知。

--------------------------------------------------------------------------------
3. 信息共享与披露
--------------------------------------------------------------------------------
M.NationWorld 绝不会将您的个人数据售卖给任何第三方。我们仅在以下极其限定的场景下共享必要信息：
• 必要服务供应商：向我们的云基础设施提供商（如第三方机房、防 DDoS 节点）及合规支付网关传输必要的数据流。
• 法律与合规要求：仅当收到具法律效力的法院传票、政府执法部门合法要求时，依法配合披露。

--------------------------------------------------------------------------------
4. 数据安全与储存
--------------------------------------------------------------------------------
• 加密传输：平台所有网络通信均强制采用 TLS 1.3 协议及 HTTPS 加密传输。
• 静态数据安全：核心数据库实行严格的访问控制权限与加密备份策略，防止数据泄露或未经授权的访问。
