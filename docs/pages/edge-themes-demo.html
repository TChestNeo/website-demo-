两个独立卡片 CSS 组件类 · 纯 CSS + 内联矢量 SVG · 零外部图片 · 可直接提取进 Vue / React

架构总原则：合成顺序是 filter → clip-path → mask—— filter: drop-shadow 与 clip-path 不能放在同一元素上 （阴影先画、随后整块被剪掉）。所以每个组件都分三层：宿主元素承载 filter 阴影栈（不剪）；::before 剪层承载 clip-path 轮廓 + 底色 + 配方层；::after 覆盖层 承载烧边/包角/扫描线（同剪、z 2、pointer-events:none）。全出血子元素（如 > img）需要自己套同一剪——伪元素的 clip 管不到兄弟元素。

① .card-parchment — 破旧的纸 / 藏宝图（褶皱折角 / 波浪边缘）

v10.6 基础轮廓 = 褶皱折角纸（右上斜切折角 + 左下圆弧卷角 + 四边微撕边）；--dark（藏宝图）= 波浪地图边缘（v10.5）。两者都是 clipPathUnits="objectBoundingBox" 的 SVG 剪切路径，按 0~1 百分比随容器任意宽高比自适应。米黄纸面 + 氧化斑驳 + 噪点 + 烧边暗角 + 悬浮投影配方不变。

编辑器 EDGE_STYLES 字段演示页对应规则
clip--pch-clip / --tech-clip（::before 与 ::after 的 clip-path；宿主不剪）
cardLayers::before 的 background-image 层栈（底色渐变 → 斑驳/网格 → 噪点瓦片）
cardOverlay::after 的 background-image 层栈（烧边暗角 / L 型包角 + 扫描线）
labelLayers演示页药丸仍走完整 ::before 剪层（input 标签无伪元素，编辑器里是简化层栈直接画在标签上）
clipSoft--soft 修饰符（浅齿/软切角多边形）
tint / border / radius / glow / color演示页 --plated 用 tint 渐变 + 边框近似（编辑器保留给标签内联配方与自动外板；组件化时建议弃用）
选中环（编辑器 filter 选中态）.is-selected 修饰符（四方向零模糊 drop-shadow trace 剪影描边）
编辑器 CSS 变量（--card-clip/--card-layers/--card-overlay/--card-tint-base）演示页直接把配方写进规则；组件化时保留变量注入方式更灵活（主题可运行时切换）
